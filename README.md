## 📌 **About HCO-Kali-Termux**
**HCO-Kali-Termux** is a powerful single-file script that installs **Kali Linux (Minimal)** with a full **XFCE GUI desktop** on Termux — **no root required**, no errors, and with a real VNC server.

This tool is professionally optimized with:
- Auto VNC configuration  
- Auto XFCE setup  
- Black-screen fix  
- Auto-resolution  
- HCO-themed interface  
- YouTube verification lock (subscribe to continue)

---

## 🚀 **Features**
- ✔ Kali Linux Minimal  
- ✔ XFCE Desktop GUI (no black screen)  
- ✔ Real TIGERVNC server  
- ✔ Auto resolution (1280×720 default)  
- ✔ Auto configure sound + DBUS  
- ✔ GUI start/stop scripts  
- ✔ One-command launch  
- ✔ Clean & stable  
- ✔ Works on **Termux Android 7+**  
- ✔ No Root Needed

## 📥 **Installation (One Command)**

### 1️⃣ Update Termux
```bash
❯ pkg update -y && pkg upgrade -y
❯ pkg install git
❯ git clone https://github.com/Hackerscolonyofficial/HCO-KALI-Termux.git
❯ cd HCO-KALI-TERMUX
❯ chmod +x * HCO-KALI-Termux.sh
❯ bash HCO-KALI-Termux.sh

```
### 💻 Usage

▶ Start Kali Terminal

./start-kali

▶ Start Kali GUI (XFCE Desktop)

./start-kali-gui

Then open VNC Viewer → enter:

127.0.0.1:5901

▶ Stop GUI

./stop-kali-gui


---

### 🔑 Setting VNC Password

Inside Kali:

proot-distro login kali
vncpasswd
