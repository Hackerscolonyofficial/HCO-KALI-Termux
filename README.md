## ⚡ About

**HCO-KALI-Termux** is a powerful one-command tool by **Hackers Colony** that lets you install and use **Kali Linux GUI inside Termux** — completely **rootless** and **error-free**.  
It automatically sets up **XFCE Desktop**, **VNC Server**, and **bVNC** support for a smooth GUI experience.

---

## 🚀 Features
- 🧩 One-command Kali installation  
- 🧠 XFCE Desktop Environment  
- 🔐 GUI unlock + YouTube verification  
- 🪄 Auto VNC configuration (IP + password auto-detect)  
- ⚙️ bVNC auto-launch or redirect to Play Store  
- 🖥️ Works on Android 10 to Android 15  
- 💪 No root required  

---

## 🧰 Installation Commands

Copy & paste these commands in Termux 👇  

```bash
pkg update -y && pkg upgrade -y
pkg install git -y
git clone https://github.com/Hackerscolonyofficial/HCO-KALI-Termux
cd HCO-KALI-Termux
chmod +x HCO-KALI-Termux.sh
bash HCO-KALI-Termux.sh

```
After installation, the tool will:

🔓 Ask you to subscribe to Hackers Colony Tech on YouTube

🎨 Display a colorful countdown

💻 Auto-start Kali with GUI

🧠 Launch bVNC or open Play Store link if not installed



---

📸 GUI Access Details

Once the setup is complete:

VNC Server IP: 127.0.0.1

Port: 5901

Default Resolution: Auto-detected

Password: You’ll set it during installation

VNC App: bVNC Free on Play Store


Then open bVNC → Connect → Enjoy full Kali GUI 🎯
